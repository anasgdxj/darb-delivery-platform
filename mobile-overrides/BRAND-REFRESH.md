# DAZREVO brand refresh

## Palette
- Smoked Obsidian: `#171C20` — primary dark canvas.
- Mineral Teal: `#1D7A6E` — light-mode primary actions and smart interaction.
- Mineral Teal Bright: `#36B6A0` — dark-mode primary actions and active states.
- Champagne Brass: `#C6A875` — premium secondary accent and route detail.
- Warm Porcelain: `#F2F0E9` — light surfaces and neutral contrast.
- Coral Alert: `#D66B63` — reserved for warnings and error emphasis.

## Android launcher identity
The adaptive launcher icon uses a custom D-shaped route monogram, a Champagne Brass route stroke, and a Mineral Teal destination beacon. The monochrome vector retains the same silhouette for themed Android icons. Existing package identity and launcher resource names remain unchanged.

## Compatibility
This change is limited to the mobile design-system palette and launcher artwork. It does not change API contracts, authentication, persisted keys, navigation, or order behavior.
